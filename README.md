# Aprender+ | Módulo C1

Aplicativo Android de treino baseado no projeto-teste Aprender+, da modalidade Desenvolvimento de Aplicativos Móveis. A experiência reúne artigos e ferramentas de estudo em Flutter.

## Funcionalidades

- Entrada por PIN de demonstração e navegação entre artigos, perfil e resumos.
- Artigos carregados de arquivos JSON e reprodução de vídeo local.
- Gravação, reprodução e exclusão de resumos em áudio.
- Opções de foto de perfil, tema e acessibilidade.

## Tecnologias

Flutter, Dart, Kotlin, Android, JSON e pacote `video_player`.

## Executar

Instale o Flutter e configure um dispositivo Android ou emulador. Na pasta do projeto:

```bash
flutter pub get
flutter run
```

O PIN de demonstração é `3245`. O projeto foi preparado para Android; recursos como microfone, câmera, galeria e brilho dependem do aparelho e das permissões concedidas. O APK gerado não está incluído no repositório. Consulte `estudo/PASSO_A_PASSO.md` para conhecer detalhes e limites da verificação feita durante o treino.

## Contexto

Exercício de preparação baseado em um projeto-teste da WorldSkills. Os recursos visuais e outros materiais fornecidos no enunciado são usados no contexto do treino.
